# UI/UX review, 2026-10-03

Code review of the whole project (head-unit app, companion, second screen), read-only. Nothing was built or run:
layout findings come from reading the code and doing the arithmetic for 1280x720, not from a rendered screen.
Items marked **checked** were re-read against the code after the first pass; the others rest on one reading.

Paths are under `app/src/main/java/com/openauto/dash/` unless they start with `companion/`, `display/` or `res/`.

Priorities: **P0** = lost or wrong data, or unsafe while driving. **P1** = visible bug or real friction.
**P2** = polish and consistency.
