# Illogical design review, 2026-10-07

Read-only pass over the head-unit app, the companion and the strings, asking one question: **where does
Dashwheel stop making sense to a driver?** Not bugs (the 2026-10-03 review covers those; nothing listed there
is repeated), but concepts, flows, names and defaults that a person would not expect. Five of the biggest
claims were re-read against the code before writing; the rest rest on one reading each.

Paths are under `app/src/main/java/com/openauto/dash/` unless they start with `companion/` or `res/`.

## By area

### Dashboards, navigation, editing

- **Edit mode has one door** (⋮ → Edit dashboards) yet an empty page offers Add and Templates outside it and a filled page offers Add only inside it. Adding a tile is one tap on an empty page and three on any other. No long-press to edit, the standard launcher idiom. `TopBar.kt:894-899, 1209`, `DashboardGrid.kt:317-319, 721-757`
- **The tile panel opens on a tap no copy mentions.** The hint says "Hold a tile to move it, drag its corner to resize it"; the tap that reaches design, text size, move and remove is undocumented. `DashboardGrid.kt:415-425`, `res/strings_dash.xml:31`, `res/strings_tour.xml:25`
- **"Move to another dashboard" moves the editor too**: tidying Home by sending three tiles away is three round trips. `AutomotiveDashboard.kt:734-756, 1564`
- **Three pictures of the cross disagree**: the move picker offers all seven spots, the indicator shows only kept ones, the template preview all seven; moving a tile to a removed spot silently brings that dashboard back. `TileOptions.kt:262-266`, `TopBar.kt:1298-1300`, `DashTemplateDialog.kt:138`
- **"Clear dashboard" (red, top-level) and "Remove dashboard" (behind the page name) are siblings with different scopes and homes**, both saying "Undo brings them back". `TopBar.kt:1214, 1177-1189`, `CanvasTabs.kt:659`
- **Dashboard options does two silent irreversible things**: moving a dashboard wipes Undo history; giving it a "Shows by itself when" trigger takes it from whichever had it. `AutomotiveDashboard.kt:1828-1835`, `CanvasTabs.kt:294-298`
- **In Canvas-over-an-app you cannot change dashboard while arranging** (tab tap opens its sheet; sheet has no Show). `CanvasTabs.kt:415, 655-668`
- **"Dashboard bar" is a per-page tile presented as a global bar.** `DashboardModel.kt:72`, `res/strings_apps.xml:126-127`, `TileOptions.kt:104`
- **The Add sheet says "apps" three ways**: tabs Widgets / Apps / Windows; a category "MEDIA & APPS"; Windows offers "In a window / Inside the tile / Side by side", an Android hosting distinction a driver cannot hold. `AddSheet.kt:80-84, 252, 289`, `res/strings_apps.xml:8, 107-115`
- **The empty page points at the dialog whose primary button is "Replace all dashboards".** `res/strings_dash.xml:181-182`, `DashTemplateDialog.kt:85-97`
- **Dashboards are named by position ("Two above Home"), renaming hides behind the edit-bar title, 16 chars max, and the name shows nowhere persistent.** `CanvasTabs.kt:135-136, 681`, `TopBar.kt:1177-1189`
- **Templates dialog mixes "pages" and "dashboards" in its own two buttons** ("Fill empty pages" / "Replace all pages" under "A template fills all seven dashboards"). `docs/screenshots/07_customise.jpg`

### Widgets and glanceability

- **55 widgets, 67 designs, no recommended path.** Templates are reachable only from the edit bar; the Add sheet's "All" is a flat grid in enum order with no Suggested, no "already added", no source ordering. `AutomotiveDashboard.kt:1122-1125`, `AddSheet.kt:287-294`
- **Unavailable kinds are half hidden, half offered unmarked.** Six kinds vanish without their source; the ten OBD kinds, the phone kinds and the internet kinds carry no chip and nothing stops adding one twice. Once placed, the same state is worded three ways ("waiting for OBD", "Needs the OBD adapter", a primary Connect button). `AddSheet.kt:235-250, 348-379`, `CarCareTiles.kt:269, 293`, `EngineTemps.kt:96`, `WidgetFaceData.kt:166-171`
- **Decorative designs are offered for Speed and Clock**: Split-flap speed, Liquid speed as a wave, Poster whose number spills off the edge by design, a Binary clock with no digits. `WidgetDesigns.kt:120`, `WidgetFaces.kt:992-1010`, `WidgetFacesModern.kt:390-405`, `WidgetSignatures.kt:1122-1143`
- **Every widget shrinks to 1x1**, below the placer's own 3-column "readable" floor; a Hero face then draws the value smaller than its title and ellipsises it. `DashboardModel.kt:206-208`, `DashboardGrid.kt:376-377`, `DashTemplates.kt:116-120`, `WidgetFaces.kt:318-324, 531`
- **Alert state is colour only, and one red means two things**: in the Telemetry face `alert = speed >= 110 || coolant >= 110`, so a red 120 is speeding or overheating. Quick switches mark on/off by tint alone while the identical Wi-Fi/BT toggles elsewhere add "On/Off". `WidgetFaces.kt:352`, `WidgetFaceData.kt:208`, `QuickSwitches.kt:129-137`, `RadioSwitches.kt:204-209`
- **Heavy overlap**: speed in six places, Wi-Fi/Bluetooth switching in five, fuel in seven, brightness in three. `BarItems.kt:96`, `DriveTiles.kt:298`, `QuickSwitches.kt:154-156`, `InfoTiles.kt:916`
- **Names that do not say what the tile shows**: "Telemetry" = engine gauges, "Head unit" = CPU/RAM monitor, "Car status" = lights/odometer/handbrake, "Screen light" and "Second screen light" two cards apart with the same icon. `WidgetCatalog.kt:135, 137`
- **Categories follow the code**: INFO & COMMS holds 8 head-unit controls; VEHICLE holds Fuel prices (internet) and CAN monitor (a developer tool); NAVIGATION holds Parking timer and Commute. `DashboardModel.kt:11-17, 33-114`
- **Default sizes give diagnostics more area than the speed** (Speed 3x2, Wi-Fi networks and Fuel log 4x3); Trip ticks at one decimal, Eco shows the drive's cost to the cent. `DashboardModel.kt:45-114`, `WidgetFaceData.kt:447, 995`
- **Two features for one action, twice**: "Share my arrival" and Directions' "On my way" both text an ETA; "Home and work" can go but not say how long, "Commute" says how long but cannot go. `DirectionsTile.kt:242`, `HomeWorkTile.kt:125-126`
- **The Speed tile spends its top row on the word SPEED and a coloured source badge** at every size, where Gear already drops its header when small. `DriveTiles.kt:158-165`, `MonitorTiles.kt:366-371`
- **In one Road-trip page two timers disagree** ("Trip · Time 36m 20s" next to "Driving time 36m 13s"); Fuel prices show "1.699 €" with three decimals in an English UI; the clock shows seconds. `docs/screenshots/20_arrangements.jpg`, `04_road_trip.jpg`

### Alerts, voice, hands-free

- **A door alert while parked with the engine off can veil the screen until tapped** (Side panel / Full designs; the shrink rule only applies when moving), though the voice is deliberately silent parked. `DoorAlertOverlay.kt:86-90`, `AlertStyles.kt:108, 176-177`, `AlertVoice.kt:21-23`
- **Fault codes are spelled "P 0 4 2 0, P 2 0 0 2. Details are on screen"**, and the screen says details are for when parked. Without a Gemini key this is the only sentence ever said. `AiMechanic.kt:406-410`, `res/strings_ai.xml:34-35`
- **Lifetime and dismissal differ per alert**: climate 4 s, volume 3 s, message 8 s but X only, doors/tyres until tapped, belt untappable, radar 1 s. Wheel "Dismiss" covers three of them, not the message card, not Gemini, not the voice. `ClimateOverlay.kt:64`, `VolumeOverlay.kt:109`, `MessageAlert.kt:48-56, 146-156`, `BeltAlertOverlay.kt:39-40`, `SteeringWheelActions.kt:123-128`
- **Climate can be a side panel over the map at every fan click and outranks Gemini**, shrinking an open conversation to a pill for 4 s. `AlertStyles.kt:110, 125-135, 156-159`
- **Three fuel warnings with three thresholds in one tank** (briefing ≤ 15 %, drive ≤ 80 km plus station, destination line). `StartupBriefing.kt:52-67`, `CarCare.kt:273-274, 376-389, 466-485`
- **The Live button goes dead while reversing**, against the project's own never-dead rule; the mic refusal sends the driver to "the microphone on the fault codes tile" they may not have. `GeminiLive.kt:243-248`
- **Briefing waits up to 37 s** (so it talks when already rolling), greets only when there is bad news, and puts the appointment last. `StartupBriefing.kt:60-78, 162-163`
- **Parking timer promises "a reminder on your phone"**; with no phone the message is dropped silently. `res/strings_widgets.xml:99`, `ParkingTimerTile.kt:78`, `PhoneLink.kt:267-270`
- **Message privacy is inconsistent**: the voice says only "Message from Alex" because passengers hear, the card shows the text to the same passengers. `AlertVoice.kt:107-110`, `MessageAlert.kt:137-140`
- **The car speaks two languages**: doors/tyres/limits/weather use the launcher's language; briefing, car care, mechanic and LPG use the AI mechanic's language picker. `AlertVoice.kt:178`, `CarCare.kt:510`, `StartupBriefing.kt:227`
- **Hands-free arrives with an empty wheel map** though the unit's own keys are already named (Phone, Hang up, Voice, Navi, Mode). `SteeringWheelStore.kt:470, 511-523`
- **"Messages" is a toggle under Voice that also kills the visual card**, with no design row like every other alert. `HandsFreeSettings.kt:69-77`, `MessageAlert.kt:69`

### Settings and menus

- **Two "Bottom bar" section headings back to back** in Display. `ThemePane.kt:168`, `BarItems.kt:419`, `SettingsScreen.kt:497-499`
- **A bare three-way switch "Automatic | This unit | Phone"** under the OBD row with no label saying it is the Bluetooth path. `SettingsScreen.kt:378, 442-469`
- **The service interval is editable in two sheets two rows apart** ("My car" seeds "Servicing" silently). `CarSettingsDialog.kt:180-181`, `MaintenanceTiles.kt:234`, `Maintenance.kt:82`
- **Speed correction exists to be matched against the speedometer while driving, but lives behind "Changes only while parked".** `SettingsScreen.kt:989-1008`, `DriveLock.kt:30`
- **"Alerts Dashwheel shows" lists Volume, Climate and Gemini Live**; volume now has three homes (Driving, Advanced, Alerts). `AlertStyleDialog.kt:98-99`, `SettingsScreen.kt:699, 810-811`
- **Two "split" controls one tap apart**: the bar's layout picker (Google Maps dock) and ⋮ → "Split screen with an app". `TopBar.kt:556-576, 902`
- **"Effects: None / Reduced / Full"** is the sunlight-legibility setting, named for the mechanism. `ThemePane.kt:109-125`, `res/strings_dash.xml:98-104`
- **Root- and firmware-gated rows follow two policies**: Alerts and Bottom bar explain what is held back; Boot logo, System app, Volume keys, Head unit keys and "Under the dashboard" just vanish. `SettingsScreen.kt:796-813`, `KeyTargets.kt:91`, `CanvasTabs.kt:869-879`
- **Steering wheel buttons and Head unit keys are split by the volume block** though both answer "what does this physical button do?". `SettingsScreen.kt:670-700`
- **Turning Demo mode on throws you out of Settings**, and it leads Advanced. `SettingsScreen.kt:785-792`
- **Language is the last row of Display**, under an 11-row reorderable list. `SettingsScreen.kt:505-506`
- **"Apps inside tiles: Not granted. Tap to get them through PMPatch3."** leads with a Magisk module name; the outcome appears only once granted; the granted row keeps tappable styling. `SettingsScreen.kt:926-955`, `res/strings_settings.xml:108-110`
- **Deep sleep wears a chevron but expands in place**, and is a diagnostic counter among settings. `SettingsScreen.kt:688-696`

Settings tree today (rail order): **Car** (10 rows + the unlabeled switch) · **Look** (gallery, Day and night, Effects) · **Display** (Screen, 4 unit rows, Bottom bar, Bottom bar, top bar, Language, Second screen) · **Alerts** (Voice ×3, "Alerts Dashwheel shows" ×8) · **Driving** (lock, tap sound, wheel, places, resume music, Deep sleep, Unit log, speed-volume ×4, head-unit keys ×3) · **Phone** · **Advanced** (Demo, Boot logo, System app, Apps inside tiles, Volume control, Save, Restore, permissions ×5, Set up again) · **About**. ⋮ → Settings always lands on Car.

### Setup, tour, companion, help

- **Skip means "never remind me"** on every step; OBD-through-phone counts as "not allowed" and keeps the nag. `SetupScreen.kt:113, 195`, `AutomotiveDashboard.kt:466-470`, `ObdBluetoothManager.kt:185-192`
- **The tour re-teaches two setup steps minutes later** (pick a theme; choose the adapter) and its OBD tip ("Dashwheel finds it") is untrue for a first adapter, which must be paired in Android Bluetooth first. `res/strings_tour.xml:67-70`, `res/strings_vehicle.xml:78`
- **Phone pairing puts three steps on one card**; the hard one (join the phone's hotspot, leaving Dashwheel and the unit's Wi-Fi) has no button, and "Waiting for the phone…" means waiting for the hotspot link. `PhoneLinkUi.kt:376-395`, `PhoneLink.kt:86-87, 356-358`
- **The companion asks for Calls (5 permissions), Agenda and Battery before any car is paired**, and counts them as "left to allow" forever with no "Not needed". `companion/.../MainActivity.kt:331-332, 1025-1028, 1126-1142`
- **Update: "Update" silently opens Android's install-unknown-apps page with no text; "Later" means never for this build.** `UpdateManager.kt:48, 106, 195-204`, `res/strings_dash.xml:190`
- **PMPatch3 dialog: jargon first, the security cost in a side clause, three sessions with no "step x of 3".** `PmPatchDialog.kt:88-100`, `res/strings_settings.xml:108-118`
- **Help is unreachable where confusion happens**: the only link is About → Project page; the wiki is never linked; pairing, OBD, AI and PMPatch dialogs have no "?". `SettingsScreen.kt:822, 856-858`
- **First-run setup vanishes when the car moves and does not come back when parked.** `AutomotiveDashboard.kt:458, 537, 1067`
- **The setup never mentions the phone companion**, and its Notifications row promises "your messages", which come from the phone link, not notification access. `res/strings_setup.xml:19-20`
- **"Not now" on the tour's welcome means never.** `TourScreen.kt` onSkip, `AutomotiveDashboard.kt:480-484`
- **Companion "Start in the car"** is a setting whose status reads "Starts in the car" while sharing is stopped, and whose off-line "Off: sharing runs all the time" reads like a warning. `companion/.../strings.xml:103-111`

## Suggested order of work

1. **First run**: make/model picker or "later"; drop OBD tiles when no adapter; one "Don't remind me"; mention the phone; re-open the setup when parked again.
2. **One voice panel**: every spoken event as a row in Settings → Alerts; Quiet in ⋮ and on the bar; everything unasked through `announce`; speed-limit keyed on the value with a cooldown.
3. **Navigation model**: default to the three-page row; persistent position in the bar's clock slot; sideways off the row does nothing (or a real grid); Canvas rail and tabs as Display options, not a theme side effect; one arrangement per screen direction.
4. **Tile tap rule**: body = more about this; world actions behind a labelled button; `DriveLock` on every list and entry tile.
5. **Vocabulary pass** from the table above, plus one verb table for Forget / Remove / Clear / Reset.
6. **Bar**: same order and labels under every skin; label the ▦ button; explain the ⋮ dot.
